## Português

Exercício de aula sobre construção de **formulários em HTML** e estilização com CSS,
sem recurso a frameworks.

### Conteúdo

```
index.html    → Estrutura do formulário e dos seus campos
style.css     → Estilos, layout e estados dos elementos
assets/       → Ícones SVG e imagens usados na interface
```

### Como ver

```bash
git clone https://github.com/ixmjst/aula-forms.git
cd aula-forms
```

Abre o `index.html` no navegador — não há dependências nem passo de compilação.

### Conceitos praticados

- Elementos de formulário: `input`, `label`, `select`, `textarea`, `button`
- Tipos de campo e validação nativa do HTML
- Associação de `label` a campo através do atributo `for`
- Layout com Flexbox
- Estilização de estados (`:focus`, `:hover`)
- Uso de ícones SVG na interface

## English

A classroom exercise on building **HTML forms** and styling them with CSS,
without any framework.

### Contents

```
index.html    → Form structure and fields
style.css     → Styles, layout and element states
assets/       → SVG icons and images used in the interface
```

### Viewing it

```bash
git clone https://github.com/ixmjst/aula-forms.git
cd aula-forms
```

Open `index.html` in a browser — no dependencies, no build step.

### Concepts practised

- Form elements: `input`, `label`, `select`, `textarea`, `button`
- Field types and native HTML validation
- Binding `label` to a field with the `for` attribute
- Flexbox layout
- Styling states (`:focus`, `:hover`)
- Using SVG icons in the interface
